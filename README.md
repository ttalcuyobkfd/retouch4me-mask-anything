## Overview

Mask Anything uses a general-purpose segmentation neural network to generate accurate pixel masks for any subject — person, product, background — with refinement controls for hair and soft edges.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Retouch4me Mask Anything** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Universal Segmentation** | Segment any subject class without category-specific models |
| **Hair Refinement** | Fine-edge detection preserves hair strands at the mask boundary |
| **Soft Edge Control** | Adjustable feathering and edge contrast for compositing |
| **Multi-Subject** | Mask multiple subjects simultaneously with independent layer outputs |
